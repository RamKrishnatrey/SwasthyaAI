# SwasthyaAI

## Safety and limitations

This repository is a local demonstration, not a medical device or clinical service. Its deterministic safety checks and any model output are not a diagnosis, and the demo has not been clinically validated. Emergency symptoms are routed to guidance to call 112 in India; this application is not an emergency service. No trained SwasthyaAI clinical model or validated clinical dataset is configured in this checkout, so agent decisions remain unavailable unless a compatible model adapter is explicitly registered. Do not enter real patient information.
